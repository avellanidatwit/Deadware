    Survivor programming

    Create a survivor with two programs: one for life, one for when it rises as a zombie. Zombies cannot be injected directly.

    You can update this program while the survivor lives. After death, select its zombie to update the zombie's behavior.

    SurvivorScript reference

    Saved scripts

    Saved programs are independent of entities. A survivor's final programs are also archived automatically when it dies.
