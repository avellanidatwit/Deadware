View survivor and zombie commands

Tab indents four spaces; Shift+Tab unindents. Select multiple lines to indent them together. Press Escape, then Tab to leave the editor.

Use WHEN conditions and OTHERWISE with MOVE north/south/east/west, MOVE_AWAY zombie, ATTACK zombie, EXPLORE, or WAIT. Changes last until restart or refresh. For zombies, use WHEN survivorNearby with CHASE survivor, then OTHERWISE with WANDER. Add a range after either nearby condition, such as WHEN zombieNearby 10 or WHEN survivorNearby 8; omit it for the default of 5 tiles. Zombies also support MOVE, EXPLORE, WAIT, and health conditions.

SurvivorScript commands

Select an entity in the editor, enter a script, then click Apply script. Commands are case-sensitive: use uppercase action names and lowercase directions and targets. The first matching rule wins each update. Survivor movement occurs only on even-numbered ticks. On other ticks, movement rules are skipped so later matching non-movement rules can run. Zombie movement can occur every tick. Put OTHERWISE last. If no rule matches, the entity waits.

Move in a specific direction

For example, replace the survivor's script with this to move east (right) one tile every two updates:

OTHERWISE
    MOVE east

Use north for up, south for down, east for right, or west for left. Movement stops at walls and grid edges. This rule repeats every movement tick (every two updates for survivors); it is not a one-time instruction. Pause and use Step to run one update at a time.

Conditions and rule syntax

Loot the nearest visible container and collect its items (wait if none is reachable within 10 tiles):

WHEN inventoryFull
    WAIT

WHEN itemsOnFloor
    PICK_UP items

WHEN containerNearby
    SEARCH container

OTHERWISE
    MOVE_TO container 10

Try searching the desk just below the starting survivor with this script (pause first to keep the survivor nearby):

WHEN containerNearby
    SEARCH container

OTHERWISE
    LOOK floor

WHEN zombieNearby 10		A visible living zombie is within the given number of tiles (default 5). Requires line of sight and excludes the observer.
WHEN survivorNearby
WHEN survivorNearby 8		Zombie only: a visible living survivor is within the given range (default 5). CHASE uses this rule's range too.
WHEN health < 20Compare the entity's own health with a nonnegative whole number. Operators: <, >, <=, >=, ==, !=.
OTHERWISEFallback if no earlier rule matched. Write one action on the next line.
# CommentLines starting with # and blank lines are ignored.

Ranges must be nonnegative whole numbers; 0 detects only the same tile. Distances count horizontal plus vertical tiles, including the range boundary. Walls block sight, including diagonally through corners; closed doors block sight and movement; open doors allow both. Losing sight ends the chase, so the next matching script rule applies. Each WHEN or OTHERWISE must be followed by exactly one action line. Changes take effect on the next update and last until refresh or restart.
